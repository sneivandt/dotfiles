# Audit

Use the scope the user names, or the active subject under discussion for a
standalone `audit`; ask if neither is clear.

- Read-only by default: do not edit files or take external actions unless
  separately authorized.
- Verify consequential claims against authoritative sources and representative
  edge cases; try to disprove serious candidates before reporting them, and
  note remaining coverage gaps or uncertainty.
- Lead with the most consequential findings (source citation, trigger/impact,
  concrete fix), consolidate shared root causes, and separate verified defects
  from inferred risks and optional improvements. Say plainly when nothing
  actionable is found.
